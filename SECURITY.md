# Security & Privacy Policy 🔒

## Privacy Philosophy
ProDocScan is built on a **100% On-Device Privacy Architecture**. 
- All document scanning, edge detection, OCR (Devanagari & English), PDF generation, and text search happen **locally on your device**.
- ProDocScan does not collect, transmit, store, or analytics-track any client financial data, scanned documents, or user metadata to external cloud servers.

## Reporting a Security Vulnerability
If you discover a security vulnerability or data leak risk within ProDocScan, please report it responsibly rather than opening a public issue.

Please email vulnerability details directly to: **techh@example.com** or contact **ProWoFlow Automation Tools**.

We will investigate and respond to all security concerns within 48 hours.
